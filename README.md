# STGB33 · Labb 4 · Kapitel 9

Interaktiv laborationsplattform för **Building the Regression Model I: Model Selection and Validation**.

Laborationen använder Surgical Unit-data och behandlar:

- undersökning av modellformen på Y-skalan;
- transformation till ln(Y);
- all possible subsets med `olsrr::ols_step_all_possible()`;
- forward och backward selection;
- validering med MSE, MSPR och jämförelser av `summary()`.

Webbplatsen är statisk och publiceras via Vercel.
